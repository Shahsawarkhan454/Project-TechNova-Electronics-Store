TechNova – Electronics Store

TechNova is a responsive electronics store website built using HTML, CSS, and JavaScript. It includes product filtering, search, price sorting, and a dynamic shopping cart counter.

(1) Features
- Responsive design
- Product category filtering
- Product search
- Price sorting
- Add-to-cart functionality

(2) Technologies Used
- HTML5
- CSS3
- JavaScript
